# Documentation index

Documentation here is public, like the repository, and written for developers building a site
on this template. The user-facing guide is [README.md](../README.md); this tree holds the
knowledge behind it. The template ships no in-product user documentation and enumerates no
routes of its own — the WordPress site built on it does.
